# Dagmawi Tesfu Portfolio

A static personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Local preview

```powershell
npx serve .
```

Open the local URL printed by the command.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository at `vercel.com/new`.
3. Leave the framework preset as **Other**.
4. Leave the build command and output directory empty.
5. Deploy.

Vercel serves `index.html` directly. No build step or environment variables are required.
