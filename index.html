AI & Consumer Utility

TabSplit

Split the bill. Not the friendship. A mobile-first receipt splitting web application that uses Google Gemini Vision to extract items and prices from restaurant receipts, allows human verification, and calculates exact per-person shares with integer minor-unit math.

Engineering highlights

  • Client-side compression (up to 20MB phone photos optimized under 5MB)
  • Gemini Vision server-side integration keeping API keys secure
  • Deterministic integer minor-unit arithmetic with largest-remainder rounding
  • Unique shareable bill links for guest access without account creation
  • Server-side recalculation, rate limiting & Supabase Row Level Security

Architecture & Stack

AI reads → Human confirms → Server calculates → Database stores the truth.

02

Privacy-First Chromium Extension

UnSub

Stop paying for things you don't use. A privacy-first Chromium browser extension that tracks subscription-domain visits locally, detects when a service hasn't been visited in 30+ days, and surfaces direct cancellation links. Zero external servers, zero telemetry, and 100% on-device storage.

Engineering highlights

  • Local visit tracking via Chrome Tabs API without saving general browsing history
  • 30-day inactivity detection powered by Manifest V3 background alarms
  • Direct account-management and cancellation links for zero-friction unsubscription
  • Native local browser notifications alerting users before recurring renewals
  • Zero-telemetry architecture — no remote backend, tracking, or data collection

Architecture & Stack

Client-side only. All subscription and visit logs reside exclusively in Chrome Local Storage.

React Vite JavaScript Manifest V3 Chrome Storage API Chrome Tabs API Chrome Alarms API Chrome Notifications API Tailwind CSS
